## 5. 资产编号规则

### 格式

```
前缀-YYYYMMDD-NN
```

### 示例

```
IT-20260826-00   ← IT设备，2026年8月26日，第1个
IT-20260826-01   ← IT设备，2026年8月26日，第2个
OF-20260826-00   ← 办公家具，2026年8月26日，第1个
PE-20260826-00   ← 生产设备，2026年8月26日，第1个
AS-20260826-00   ← 其他分类，2026年8月26日，第1个
```

### 校验规则

1. 正则：`^(IT|OF|PE|AS)-(\d{8})-(\d{2})$`
2. 日期必须为真实日历日期（如 2026-02-30 拒绝）
3. 不得与现有编号重复

### 生成规则

- 当日同分类内递增，从 00 开始
- 每日每分类最多 100 个（序号 00-99）
- 超过 99 抛出 ValueError

## 6. JSON 扩展字段

### config 字段结构

```json
{
    "system_info": [
        {
            "ip": "192.168.1.101",
            "login_method": "SSH",
            "port": 22,
            "username": "admin",
            "note": "办公笔记本"
        }
    ]
}
```

### system_info 子项字段

| 字段 | 说明 |
| --- | --- |
| ip | IP 地址 |
| login_method | 登录方式：SSH/Telnet/Web/RDP/Console/其他 |
| port | 端口号 |
| username | 账号 |
| note | 备注 |
| custom_method | 自定义登录方式（login_method=其他时） |

> 注意：password 字段已移除，不再保存密码。
