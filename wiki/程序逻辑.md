# 程序逻辑：cmdb 插件

## 1. 入口与路由

`cmdb/plugin.py` 中的 `CMDBPlugin` 继承 `BasePlugin`：

- `get_metadata()`：返回 `name=cmdb`、`version`（当前 `20260824-V2`）等。
- `on_load()`：调用 `common.init_db()` 初始化 SQLite（`plugins/cmdb/data/cmdb.db`）；首次运行 `seed_if_empty(force=True)` 写入种子数据。
- `get_routes()`：返回 `APIRouter(prefix="/api/cmdb")`，所有资产 / 机柜 / 报表 / 备份接口集中定义于此。
- `get_menus()`：注册「CMDB 资产管理」一级菜单与五个子页。

> 注意路由注册顺序：`/api/cmdb/assets/batch-update`、`/assets/batch-delete`、`/assets/import-template`、`/assets/import-csv` 等**固定路径**必须注册在 `/assets/{asset_id}` 通配路由之前，否则会被 `{asset_id}` 截走。

## 2. 模块划分

`cmdb/modules/` 按职责拆分，被 `plugin.py` 路由调用：

| 模块 | 职责 |
| --- | --- |
| `assets.py` | 资产增删改查、分页/筛选/排序、批量更新盘点时间、批量删除、U 位绑定 |
| `racks.py` | 机柜管理、上架/下架、删除（含 force 解绑） |
| `ports.py` | 端口配置读写 |
| `dashboard.py` | 仪表盘统计 |
| `maintenance.py` | 维保列表与到期预警 |
| `reports.py` | 部门汇总、资产盘点报表 |
| `backup.py` | 全量 JSON 导出/导入（merge/overwrite） |
| `import_csv.py` | CSV 模板生成与批量导入解析 |

## 3. 数据模型（SQLite）

核心表（由 `common.init_db()` 创建）：

- `assets`：资产主表（id、asset_no、name、category、subtype、user、dept、location、status、price、warranty_expire、rack_id、u_start、u_height、ports(JSON)、inventory_time 等）。
- `racks`：机柜表（rack_id、total_u、位置等）。
- 端口以 JSON 字段存储在 `assets.ports`，避免额外的端口表 JOIN。

## 4. 安全与审计

- 所有接口通过 `Depends(get_current_user)` 鉴权。
- 写操作（增/删/改/导入/批量/备份）均调用 `audit_log("cmdb_xxx", detail, "success", username=user)`，可在框架「日志中心」追溯。
- 报表 / 资产名称等用户可写内容统一经 `_esc()`（HTML 转义）后再拼入 HTML，防止存储型 XSS。

## 5. 报表生成

- HTML 报表：`_build_report_html()` 将 headers/rows 渲染为带样式的 `<table>`，资产名/备注均转义。
- CSV 报表：写入 UTF-8 BOM（`\ufeff`）并声明 `charset=utf-8`，确保 Excel 打开中文不乱码（与导入模板一致）。

## 6. 导入导出

- CSV 导入：解析文本 → 逐行校验 → 返回 `{added, failed, errors}`；编号重复 / 必填缺失会进失败列表。
- JSON 备份：导出时 `backup.export_all()` 收集资产 + 机柜 + 端口；导入 `backup.import_all(data, mode)` 按资产编号匹配。
- 备份导入失败（JSON 解析错误 / 缺内容）返回 400，不污染现有数据。
