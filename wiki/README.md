## 快速开始

```bash
# 1. 安装：将插件目录复制到框架 plugins/ 下
cp -r NetCore_cmdb/ plugins/NetCore_cmdb/

# 2. 重启框架，自动完成：
#    - 建库（data/cmdb.db）
#    - 写入演示数据（5 个机柜 + 13 个资产 + 端口）
#    - 生成配置文件 data/config.yaml

# 3. 访问左侧菜单「CMDB 资产管理」
```

> 部署说明详见 [教程 § 1 部署](教程.md#1-部署)。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | Python 3.8+ / FastAPI / SQLite3（WAL 模式） |
| 前端 | Vue 3 + Element Plus + nc-table（框架内置） |
| 数据库 | `plugins/NetCore_cmdb/data/cmdb.db`（运行时生成） |
| 配置 | `plugins/NetCore_cmdb/data/config.yaml`（运行时自动生成） |
