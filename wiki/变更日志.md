## 版本历史

### 20260827-V1

**功能**

- 前端模块化拆分：`cmdb_common.js` 拆为 `cmdb_asset_form.js`、`cmdb_asset_detail.js`、`cmdb_page_header.js` 三个独立组件文件。
- IT 资产页面拆分：`cmdb_it.js` 拆为 `cmdb_it_assets.js`（资产列表）和 `cmdb_it_racks.js`（机柜视图），菜单独立展示。
- 办公/实物资产页面拆分：`cmdb_physical.js` 拆为 `cmdb_office.js`（办公家具）和 `cmdb_production.js`（生产设备），菜单独立展示。
- 表单重构：`cmdb-form-main`/`cmdb-form-collapse` 改为框架标准 `nc-form-card`/`nc-section`/`nc-section-title`/`nc-form-hint` 样式。
- 端口双向联动：保存资产时自动同步对端端口的 remote_device / remote_port / status 字段；对端端口不存在时自动创建；冲突时弹窗提示用户覆盖或取消。
- 新增 `POST /api/cmdb/ports/sync-remote` 端口同步 API（支持 force 覆盖）。
- 机柜视图标签改名：去掉 "(X台)" 后缀。

**修复**

- 修复旧前端文件（cmdb_it.js、cmdb_physical.js）残留导致的菜单重复问题。

### 20260826-V5

**修复**

- IT 资产列表移除「分类」列（该页固定筛选 IT 设备，分类列冗余）。
- 修复 `clearSelection is not a function` 错误（框架 `nc-table` 组件添加 `clearSelection()` 代理方法）。

### 20260826-V4

**功能**

- 资产编号规则改为 `前缀-YYYYMMDD-NN`（当日顺序分配，如 IT-20260826-00）。
- 新增资产编号格式校验（正则 + 日期有效性）。
- 前端表单新增资产编号格式预检。
- 插件配置 `data/config.yaml` 改为自动生成（版本号以 `plugin.py` 为唯一来源）。
- 源码仓库不再包含 `config.yaml`。

**修复**

- 修复演示数据资产编号唯一性（13 个资产编号全部唯一）。
- 修复 `common.py` 缺少 `from core.logger import get_logger` 导致的加载失败。
- 修复 CI 流程：路径修正、staging 打包、新增 Python 语法检查、actions 版本升级。

### 20260826-V3

**功能**

- IT/实物资产页改为分页拉取（后端单页上限 200，前端按 total 循环取回）。
- 新增资产编号自动生成规则（前缀-当日日期-序号）。
- 新增资产编号唯一性预检（create_asset / update_asset）。
- 新增批量更新盘点时间、批量删除接口。
- 新增 CSV 批量导入功能（对标数通配置卫士）。
- 新增仪表盘统计页。
- 新增维保管理页。
- 新增报表中心（资产盘点/部门汇总/维保预警，HTML/CSV 导出）。
- 新增备份导出/导入（JSON，merge/overwrite 模式）。
- 新增机柜 U 位管理（上架/下架/删除保护/force 解绑）。
- 新增端口配置（整表替换，网络设备自动识别）。
- 新增资产详情弹窗（基础信息/采购维保/系统信息/端口/操作按钮）。
- 新增资产标签打印（含离线二维码）。
- 新增资产调拨、续保、报修、报废操作。

## 升级注意事项

1. 删除 `data/config.yaml`（重启后自动生成）。
2. 资产编号格式变更：旧数据中的编号不受影响（仅新生成/手填时校验）。

### 从 V5 升级到 20260827-V1

1. 更新 `frontend/` 目录下所有 JS 文件（删除旧文件，添加新文件）。
2. 更新 `plugin.py`（菜单结构变更）。
3. 更新 `modules/ports.py`（新增 `sync_remote_port` 函数）。
4. 删除旧文件：`cmdb_it.js`、`cmdb_physical.js`（已拆分为独立文件）。
5. 清除浏览器缓存。

### 从 V4 升级到 V5

1. 更新 `ui/framework.js`（`nc-table` 添加 `clearSelection()` 方法）。
2. 更新 `cmdb_it.js`（移除「分类」列）。
3. 清除浏览器缓存。

## 版本号规则

- 格式：`YYYYMMDD-V#`（如 20260826-V5）
- 每次发布递增 `V#`（同一天内可多次发布）
- 版本号唯一来源：`plugin.py` → `get_metadata()` → `version`
- `config.yaml` 自动同步版本号
