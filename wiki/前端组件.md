## 1. 组件注册机制

### 1.1 页面注册

通过 `window.NC.registerPage(id, component, title, path)` 注册：

```javascript
window.NC.registerPage('cmdb_it', {
    template: `...`,
    data() { return {...}; },
    methods: {...},
}, 'IT 资产', '/cmdb/it-assets');
```

| 参数 | 说明 |
| --- | --- |
| id | 组件唯一标识 |
| component | Vue 组件选项对象 |
| title | 页面标题（显示在菜单中） |
| path | 路由路径（与 `get_menus()` 中的 `path` 对应） |

### 1.2 共享组件（无路径）

不传 `path` 参数，注册为全局组件供其他页面复用：

```javascript
window.NC.registerPage('CmdbAssetForm', {
    template: `...`,
}, '资产表单');  // 无 path
```

使用：`<CmdbAssetForm ref="formDlg" @saved="refresh"/>`

### 1.3 前端清单

框架 `/api/plugins/frontend-manifest` 自动收集所有 `frontend/*.js` 文件，无需手动注册。

## 2. 共享组件 API

### 2.1 CmdbAssetForm（资产新建/编辑表单）

**注册 ID**：`CmdbAssetForm`

**Props**：无（通过 `open()` 方法传参）

**Events**

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| saved | - | 保存成功后触发 |

**方法**

| 方法 | 参数 | 说明 |
| --- | --- | --- |
| `open(asset, opts)` | asset: `{id}` 或 `null`；opts: `{categories, defaultCategory}` | 打开表单 |

**opts 参数说明**

```javascript
{
    categories: ['IT设备'],              // 限定可选分类（由所在页面传入）
    defaultCategory: '办公家具',          // 默认选中分类
}
```

**使用示例**

```javascript
// 新建 IT 资产
this.$refs.formDlg.open(null, { categories: ['IT设备'] });

// 编辑资产
this.$refs.formDlg.open(row, { categories: ['IT设备'] });

// 新建办公/实物资产
this.$refs.formDlg.open(null, { categories: ['办公家具', '生产设备'], defaultCategory: '办公家具' });
```

**表单折叠区**

| 折叠区 | 内容 | 显示条件 |
| --- | --- | --- |
| 常用信息 | 分类/编号/名称/子类/品牌/型号/SN/颜色/备注 | 始终显示 |
| 采购与合同 | 合同号/供应商/原值/购买日期/保修到期 | 默认折叠 |
| 归属与位置 | 使用人/部门/位置/状态/盘点时间/机柜/U位 | 默认折叠 |
| 系统信息 | IP/登录方式/端口/账号/备注（多行表格） | 仅 IT 设备 |
| 端口信息 | 端口号/名称/速率/MAC/IP/对端/状态（多行表格） | 仅 IT 设备 |

### 2.2 CmdbAssetDetail（资产详情弹窗）

**注册 ID**：`CmdbAssetDetail`

**Events**

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| changed | - | 资产状态变更后触发 |
| edit | `{id}` | 点击「编辑资产」时触发 |

**方法**

| 方法 | 参数 | 说明 |
| --- | --- | --- |
| `open(asset)` | asset: `{id}` | 打开详情弹窗 |

**使用示例**

```javascript
this.$refs.detailDlg.open(row);
```

**详情内容**

| 区域 | 内容 |
| --- | --- |
| 基础信息 | 编号/分类/子类/名称/品牌型号/SN/颜色/存储/内存/使用人/位置/状态 |
| 采购与维保 | 合同号/供应商/购买日期/原值/保修到期/盘点时间 |
| 系统信息 | IP/登录方式/端口/账号/备注（仅 IT 设备且有数据时显示） |
| 端口信息 | 端口号/名称/速率/MAC/IP/对端/状态（仅网络设备且有端口时显示） |
| 操作按钮 | 编辑/报修/调拨/续保/打印标签/报废 |

## 3. 样式体系

### 3.1 样式注入

`cmdb_common.js` 启动时一次性注入 CSS（ID: `cmdb-plugin-style`），仅注入一次。

### 3.2 主题色

```css
.cmdb-page {
    --el-color-primary: #4361ee;
    --el-color-primary-light-3: #5a73f0;
    --el-color-primary-light-5: #8593f5;
    --el-color-primary-light-7: #b3bdf9;
    --el-color-primary-light-8: #c9d1fb;
    --el-color-primary-light-9: #e4e9fd;
    --el-color-primary-dark-2: #3651c4;
}
```

### 3.3 关键样式类

| 类名 | 用途 |
| --- | --- |
| `.cmdb-page` | 页面根容器（含主题变量） |
| `.cmdb-stat` | 统计卡片（渐变背景，hover 上浮） |
| `.cmdb-rack-card` | 机柜卡片（hover 边框高亮） |
| `.cmdb-mini-slot` | 机柜 U 位缩略图（绿色=占用，灰色=空闲） |
| `.cmdb-rack-unit` | 机柜 U 位详情行（占用=绿色背景，空闲=灰色） |
| `.cmdb-ph` | 页面标题栏（左侧蓝色竖条 + 标题 + 操作区） |
| `.cmdb-form-main` | 表单常用信息区（蓝色背景） |
| `.cmdb-form-collapse` | 表单折叠区样式 |
| `.cmdb-section-title` | 章节标题（左侧蓝色竖条） |
| `.cmdb-maint-alert` | 维保预警条（红色=已过保，橙色=即将到期） |
| `.cmdb-report-card` | 报表卡片 |
| `.cmdb-topo-node` / `.cmdb-topo-line` | 拓扑节点/连线（预留） |

## 4. 子类选项配置

### 4.1 全局配置

```javascript
window.CMDB_SUBTYPE_OPTIONS = {
    'IT设备': ['服务器', '交换机', '路由器', '防火墙', 'AP', '笔记本', '台式机', '显示器', '打印机', '手机', '平板', 'UPS', '存储设备', '安防监控', '其他'],
    '办公家具': ['办公桌', '办公椅', '文件柜', '会议桌', '沙发', '货架', '保险柜', '白板', '其他'],
    '生产设备': ['机床', '生产线', '检测设备', '包装设备', '起重设备', '空压机', '焊接设备', '模具', '其他'],
};
```

### 4.2 使用方式

- 表单中根据当前分类动态加载子类下拉选项。
- 支持「选择或输入自定义」（`filterable allow-create`）。
- 切换分类时，若原子类不属于新分类的常用项则清空。

## 5. 工具函数

### 5.1 离线二维码

```javascript
window.CMDB_QR_DATAURL(text, cellSize)
```

- 参数：`text` 二维码内容，`cellSize` 像素大小（默认 4）。
- 返回：dataURL（GIF 格式），失败返回空串。
- 基于 `qrcode-generator` 库（MIT），纯离线生成，不依赖后端。

### 5.2 保修天数计算

各页面内部实现（非全局）：

```javascript
daysLeft(row) {
    if (!row.warranty_expire) return null;
    const t = new Date(); t.setHours(0,0,0,0);
    const e = new Date(row.warranty_expire); e.setHours(0,0,0,0);
    return Math.round((e - t) / 86400000);
}
```

返回值：正数=剩余天数，负数=已过保天数，null=无保修信息。

### 5.3 保修状态标签

```javascript
warrantyType(row) {
    const d = this.daysLeft(row);
    if (d === null) return 'info';
    return d < 0 ? 'danger' : d <= 30 ? 'warning' : 'success';
}
warrantyText(row) {
    const d = this.daysLeft(row);
    if (d === null) return '无维保';
    return d < 0 ? '已过保'+(-d)+'天' : '剩余'+d+'天';
}
```

| 状态 | 标签颜色 | 文本 |
| --- | --- | --- |
| 无保修 | info (灰) | 无维保 |
| 已过保 | danger (红) | 已过保X天 |
| ≤30天 | warning (橙) | 剩余X天 |
| >30天 | success (绿) | 剩余X天 |
