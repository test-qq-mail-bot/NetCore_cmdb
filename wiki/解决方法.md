## 部署与启动

### 1. 插件不加载 / 菜单不显示

**原因**
- 目录结构不正确（`plugin.py` 不在预期位置）。
- 依赖未安装（`requirements.txt` 中的包）。
- `on_load()` 抛出异常。

**排查**
1. 确认目录为 `plugins/NetCore_cmdb/` 且含 `plugin.py`。
2. 检查框架日志 `data/logs/` 中 `插件 cmdb 加载失败` 信息。
3. 框架故障隔离：单插件失败不影响其他插件。

**解决**
```bash
# 检查目录结构
ls plugins/NetCore_cmdb/plugin.py

# 安装依赖
pip install -r plugins/NetCore_cmdb/requirements.txt
```

### 2. config.yaml 报错

**原因**
- `data/config.yaml` 损坏或被手工编辑。

**解决**
- 删除 `data/config.yaml`，重启框架自动重建。
- 请勿手工编辑该文件。

## 资产管理

### 3. 新增资产报「编号重复」(400)

**原因**
- `asset_no` 建有唯一约束，与现有资产编号冲突。

**解决**
- 修改编号，或留空由系统自动生成。

### 4. 资产编号格式错误 (400)

**原因**
- 手填编号不符合 `前缀-年月日-2位序号` 格式。

**正确格式**
```
IT-20260826-00    ← 正确
OF-20260826-01    ← 正确
PE-20260826-00    ← 正确
IT-2026-08-26-00  ← 错误（日期格式不对）
IT20260826-00     ← 错误（缺少分隔符）
```

### 5. 名称为空 (400)

**原因**
- 资产名称（name）为必填项。

**解决**
- 填写资产名称后重试。

### 6. 批量更新盘点时间无效 (400)

**原因**
- 请求体格式错误。

**正确格式**
```json
{"ids": [1, 2, 3], "inventory_time": "2026-08-25"}
```

**校验规则**
- `ids` 必须为非空整数数组。
- `inventory_time` 必须为 `YYYY-MM-DD` 格式的合法日期。

### 7. 资产详情端口不显示

**原因**
- 端口存于 `assets.config` JSON 字段，若为空说明未录入。
- 资产未标记为网络设备（`is_network_device=0`）。

**解决**
- 编辑资产 → 展开「端口信息」→ 添加端口。
- 子类为「交换机/路由器/防火墙/AP」时自动标记为网络设备。

## 机柜管理

### 8. 机柜删除被拒 (400 "机柜内还有 N 台设备")

**原因**
- 默认保护：机柜内有已上架设备时拒绝删除。

**解决**
1. 先到各资产「编辑」→ 清空「所属机柜」→ 保存（逐台下架）。
2. 或在机柜 U 位详情弹窗中逐台「移出」。
3. 或确认后点击「解绑并删除」（先解绑下架，再删机柜，资产台账不丢）。

### 9. 调小机柜总 U 数报 400

**原因**
- 已有设备占用超过新总 U 数，更新被拒（避免设备越界）。

**解决**
- 先下架高位设备（移出或调整 U 位），再调小总 U 数。

### 10. 设备上架报「U 位冲突」

**原因**
- 起始 U 位 + U 高 - 1 与同机柜其他资产的 U 位区间重叠。

**解决**
- 选择不重叠的 U 位区间。
- 可在机柜视图中查看哪些 U 位已被占用。

### 11. 设备上架报「超出机柜总 U 数」

**原因**
- 起始 U 位 + U 高 - 1 > 机柜总 U 数。

**解决**
- 调整起始 U 位或 U 高，使其不超过机柜总 U 数。

## CSV 导入

### 12. CSV 导入失败 / 全部进失败列表

**原因**
- 仅支持 CSV（不支持 xlsx）。
- 文件含 BOM 导致首列错位。
- 表头缺少 `name` 列。

**解决**
1. 下载官方模板，按模板格式填写。
2. 首行 `#` 注释不要删（导入时自动跳过）。
3. 确认用 CSV 格式保存（不是 xlsx）。

### 13. 导入部分行失败

**常见失败原因**

| 错误信息 | 原因 | 解决 |
| --- | --- | --- |
| name 为必填项 | 名称列为空 | 填写名称 |
| 资产编号已存在 | 编号重复 | 修改编号或留空自动生成 |
| U 位冲突 | 与同机柜设备重叠 | 调整 U 位 |
| 超出机柜总 U 数 | U 位超出范围 | 调整 U 位或 U 高 |
| 机柜不存在 | rack_id 填写了不存在的机柜 | 先创建机柜或填写正确的编号 |

### 14. 导入后端口不显示

**原因**
- CSV 模板不含端口列，端口需通过编辑资产或 API 单独录入。
- 子类未命中 `NETWORK_SUBTYPES`（交换机/路由器/防火墙/AP/无线AP），未自动标记为网络设备。

**解决**
- 编辑资产 → 展开端口区 → 手动添加端口。
- 或通过 API `PUT /api/cmdb/assets/{id}/ports` 批量更新。

## 报表导出

### 15. 报表在 Excel 打开中文乱码

**原因**
- 不应发生：CSV 导出已带 UTF-8 BOM。

**解决**
- 确认用 Excel「数据 → 从文本」导入并选 UTF-8。
- 或直接用 HTML 报表打印。
- 或用 WPS Office 打开（自动识别 BOM）。

### 16. 报表导出 400 "type 仅支持 inventory/dept/warranty"

**原因**
- `type` 参数值非法。

**解决**
- 使用 `inventory`（资产盘点）、`dept`（部门汇总）、`warranty`（维保预警）之一。

## 备份恢复

### 17. 备份导入后数据不对

**原因**
- `mode` 选择错误。

**mode 说明**

| mode | 行为 | 适用场景 |
| --- | --- | --- |
| merge | 按资产编号/SN 匹配，存在则更新、不存在则新增 | 日常恢复（安全，不丢数据） |
| overwrite | 清空现有数据后整表还原 | 灾难恢复（危险，丢失现有数据） |

**解决**
- 确认 mode 选择正确。
- 查看导入结果中的 added/updated/skipped 计数，核对是否与预期一致。

### 18. 备份导入报 400 "JSON 解析失败"

**原因**
- 上传的文件不是有效的 JSON 格式。

**解决**
- 确认使用本插件导出的 JSON 备份文件。
- 用文本编辑器打开检查 JSON 格式是否正确。

### 19. 备份导入报 400 "缺少 assets 列表"

**原因**
- JSON 根节点缺少 `assets` 字段。

**解决**
- 确认 JSON 结构为 `{ "meta": {...}, "racks": [...], "assets": [...] }`。

## 前端问题

### 20. 批量删除报错 `clearSelection is not a function`

**原因**
- 已修复：框架 `nc-table` 组件已添加 `clearSelection()` 代理方法。

**解决**
- 更新框架 `ui/framework.js`（加 `ref="innerTable"` + `clearSelection()` 方法）。
- 更新后清除浏览器缓存。

### 21. IT 资产列表显示「分类」列

**原因**
- 已修复：`cmdb_it.js` 中已移除「分类」列定义。

**解决**
- 更新 `cmdb_it.js`，移除 `cols` 数组中的 `{ label: '分类', ... }` 和对应的 slot 模板。

### 22. 页面加载后空白

**原因**
- 前端 JS 文件未正确加载。
- 后端 API 返回错误。

**排查**
1. 打开浏览器开发者工具 → Console，查看报错信息。
2. 打开 Network 标签，检查 API 请求是否成功。
3. 检查框架日志中是否有插件加载错误。

## 数据库

### 23. 数据库位置

数据库文件位于 `plugins/NetCore_cmdb/data/cmdb.db`（运行时生成，不进仓库）。

### 24. 数据库迁移

- 直接拷贝 `cmdb.db` 文件即可迁移。
- 或通过「全量备份 JSON」做跨环境迁移（推荐）。

### 25. 重置演示数据

```bash
# 停止框架
# 删除数据库文件
rm plugins/NetCore_cmdb/data/cmdb.db
# 重启框架（自动写入演示数据）
```
