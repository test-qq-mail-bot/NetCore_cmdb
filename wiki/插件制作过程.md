## 1. 目录约定

```
plugins/your_plugin/
├── plugin.py              # 入口：路由 + 菜单 + 生命周期
├── common.py              # 数据库连接、建表、公共工具
├── modules/               # 业务模块（按职责拆分）
│   ├── module_a.py
│   └── module_b.py
├── frontend/              # 前端页面脚本
│   ├── page_a.js
│   └── page_b.js
├── requirements.txt       # 插件依赖
├── data/                  # 运行时（不进仓库）
│   ├── your_plugin.db
│   └── config.yaml
└── wiki/                  # 文档
```

### 关键约定

- **路由集中定义**：简单插件在 `plugin.py` 内集中定义（CMDB 方式）；接口多的插件可拆分到 `routes/` 包（netconfig_guardian 方式）。
- **data/ 目录不进仓库**：`.gitignore` 排除，运行时自动创建。
- **config.yaml 自动生成**：版本号以 `plugin.py` 为唯一来源，避免双处维护。

## 2. 继承 BasePlugin

```python
from fastapi import APIRouter, Depends
from core.auth import get_current_user
from plugins.base_plugin import BasePlugin

class YourPlugin(BasePlugin):
    def get_metadata(self) -> dict:
        return {
            "name": "your_plugin",           # 唯一标识
            "version": "20260826-V1",        # 版本号
            "description": "插件描述",
            "author": "Your Name",
        }

    def on_load(self) -> bool:
        """插件加载时调用，返回 True 表示成功。"""
        from plugins.your_plugin import common
        common.init_db()                    # 建表
        # common.seed_if_empty(force=True)  # 首次运行写入种子数据
        # common.ensure_config(version)     # 自动生成配置文件
        return True

    def get_routes(self) -> APIRouter:
        router = APIRouter(prefix="/api/your_plugin")
        # ... 注册接口
        return router

    def get_menus(self) -> list:
        return [{
            "id": "your_plugin",
            "label": "你的插件",
            "icon": "doc",
            "children": [
                {"id": "page_a", "label": "页面A", "path": "/your_plugin/page-a"},
            ],
        }]
```

## 3. 路由注册

### 3.1 基本模式

```python
@router.get("/items")
async def list_items(user: str = Depends(get_current_user)):
    return items.list_all()

@router.post("/items")
async def create_item(req: dict, user: str = Depends(get_current_user)):
    try:
        item_id = items.create(req)
    except ValueError as e:
        return JSONResponse(status_code=400, content={"detail": str(e)})
    audit_log("your_plugin_add", "新增: %s" % req.get("name"), "success", username=user)
    return {"success": True, "id": item_id}
```

### 3.2 路由注册顺序

**固定路径必须在通配路由之前注册**：

```python
# 正确
router.post("/items/batch-delete", ...)  # ← 先
router.delete("/items/{item_id}", ...)   # ← 后

# 错误（batch-delete 会被 {item_id} 截走）
router.delete("/items/{item_id}", ...)
router.post("/items/batch-delete", ...)
```

### 3.3 批量接口模式

```python
@router.post("/items/batch-delete")
async def batch_delete(req: dict, user: str = Depends(get_current_user)):
    ids = req.get("ids")
    if not isinstance(ids, list) or not ids:
        return JSONResponse(status_code=400, content={"detail": "请传入非空 id 列表"})
    n = items.batch_delete(ids)
    audit_log("your_plugin_batch_delete", "批量删除: %d 条" % n, "success", username=user)
    return {"success": True, "deleted": n}
```

## 4. 数据访问层

### 4.1 数据库连接

```python
# common.py
import sqlite3
from pathlib import Path
from core.config_loader import PLUGINS_DIR

DB_PATH = PLUGINS_DIR / "your_plugin" / "data" / "your_plugin.db"

def _connect() -> sqlite3.Connection:
    DB_PATH.parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(str(DB_PATH), timeout=30)
    conn.row_factory = sqlite3.Row
    try:
        conn.execute("PRAGMA foreign_keys = ON")
        conn.execute("PRAGMA busy_timeout=5000")
        conn.execute("PRAGMA journal_mode=WAL")
    except sqlite3.DatabaseError:
        pass
    return conn
```

### 4.2 建表

```python
def init_db():
    was_new = not DB_PATH.exists()
    conn = _connect()
    try:
        conn.executescript("""
        CREATE TABLE IF NOT EXISTS items (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            ...
        );
        """)
        conn.commit()
    finally:
        conn.close()
    return was_new
```

### 4.3 CRUD 模式

```python
def create_item(data: dict) -> int:
    conn = _connect()
    try:
        conn.execute("BEGIN IMMEDIATE")  # 写锁，防竞态
        cur = conn.execute(
            "INSERT INTO items (name, ...) VALUES (?, ...)",
            (data.get("name"), ...)
        )
        conn.commit()
        return cur.lastrowid
    finally:
        conn.close()

def list_items(page=1, size=20) -> tuple:
    conn = _connect()
    try:
        total = conn.execute("SELECT COUNT(*) AS c FROM items").fetchone()["c"]
        rows = conn.execute(
            "SELECT * FROM items ORDER BY id DESC LIMIT ? OFFSET ?",
            (size, (page - 1) * size)
        ).fetchall()
        return [dict(r) for r in rows], total
    finally:
        conn.close()
```

## 5. 鉴权与审计

### 5.1 鉴权

每个接口加 `user: str = Depends(get_current_user)`：

```python
@router.get("/items")
async def list_items(user: str = Depends(get_current_user)):
    ...
```

### 5.2 审计日志

写操作调用 `audit_log()`：

```python
from core.audit import audit_log

audit_log(
    "your_plugin_item_add",     # 操作类型
    "新增项目: %s" % name,       # 详情
    "success",                   # 状态
    username=user                # 用户
)
```

### 5.3 XSS 防护

用户可写内容拼入 HTML 前统一转义：

```python
import html

def _esc(value) -> str:
    return html.escape("" if value is None else str(value), quote=True)

# 使用
"<td>%s</td>" % _esc(asset["name"])
```

## 6. 前端页面注册

### 6.1 页面注册

```javascript
// frontend/page_a.js
(function () {
    window.NC.registerPage('your_plugin_page_a', {
        template: `
        <div class="cmdb-page">
          <h2>页面 A</h2>
          <nc-table :data="rows" :columns="cols"></nc-table>
        </div>`,
        data() { return { rows: [], cols: [] }; },
        methods: {
            async load() {
                const r = await http.get('/api/your_plugin/items');
                this.rows = r.data.items || [];
            },
        },
        mounted() { this.load(); },
    }, '页面 A', '/your_plugin/page-a');
})();
```

### 6.2 路径对应

`registerPage` 的第 4 个参数 `/your_plugin/page-a` 必须与 `get_menus()` 中的 `path` 一致。

### 6.3 共享组件

通过 `registerPage` 注册为全局组件（不挂载路径），供其他页面以 `<ComponentName>` 复用：

```javascript
window.NC.registerPage('YourComponent', {
    props: { asset: Object },
    template: `<div>{{asset.name}}</div>`,
}, '组件名称');
```

### 6.4 前端清单

框架 `/api/plugins/frontend-manifest` 自动收集所有 `frontend/*.js`，无需手动注册。

## 8. 可复用经验

### 8.1 报表

- 统一 `_build_report_html()` + CSV BOM，避免中文乱码。
- CSV 导出时消毒 `= + - @` 开头字段，防公式注入。

### 8.2 安全

- 用户可写内容一律 HTML 转义，防 XSS。
- LIKE 搜索转义 `%` 和 `_` 通配符。
- 危险操作（删除）默认拒绝 + 二次确认。

### 8.3 数据保护

- 删除机柜不连带删除资产（解绑不删台账）。
- 批量删除通过 ON DELETE CASCADE 删除关联端口。
- 备份导入失败不污染现有数据。

### 8.4 并发安全

- 写事务使用 `BEGIN IMMEDIATE` 取写锁。
- U 位校验与写入在同一事务内完成。

### 8.5 版本管理

- 版本号唯一来源：`plugin.py` → `get_metadata()` → `version`。
- 配置文件自动同步，避免双处维护。

### 8.6 前端分页

- 后端单页上限 200（超过返回 422）。
- 前端全量拉取后客户端分页（上限 10000 条）。
- 兼顾性能与用户体验。
