# 教程：CMDB 资产配置管理

> 本文档面向最终用户与运维人员，涵盖从安装到日常使用的全部操作。

---

## 1. 部署

### 1.1 安装步骤

```bash
# 1. 下载本仓库
git clone https://github.com/test-qq-mail-bot/NetCore_cmdb.git

# 2. 将插件目录复制到框架 plugins/ 下
cp -r NetCore_cmdb/ plugins/NetCore_cmdb/
# 最终路径：plugins/NetCore_cmdb/plugin.py（入口必须存在）

# 3. 重启 NetCore Framework
# 启动后左侧菜单自动出现「CMDB 资产管理」
```

### 1.2 目录结构（运行时）

```
plugins/NetCore_cmdb/
├── plugin.py              # 入口：路由 + 菜单注册
├── common.py              # 数据库、种子数据、公共工具
├── modules/               # 业务模块（assets/racks/ports/dashboard/maintenance/reports/backup/import_csv）
├── frontend/              # 前端页面（cmdb_it.js/cmdb_physical.js/cmdb_dashboard.js/cmdb_maintenance.js/cmdb_reports.js/cmdb_common.js）
├── requirements.txt       # 插件依赖（仅 fastapi）
├── data/                  # 运行时目录（自动创建，不进仓库）
│   ├── cmdb.db            # SQLite 数据库（首次启动自动创建）
│   └── config.yaml        # 运行时配置（自动同步版本号，无需手动编辑）
└── wiki/                  # 本文档目录
```

### 1.3 首次运行与演示数据

- 首次启动时若 `data/cmdb.db` 不存在，插件自动写入演示数据：
  - **5 个机柜**：CAB-A01 / CAB-A02 / CAB-A03 / CAB-B05 / CAB-C01
  - **13 个资产**：覆盖 IT 设备（10 个）、办公家具（2 个）、生产设备（1 个）
  - **端口连接**：交换机/服务器/路由器/防火墙/AP 均含端口数据
  - **状态全覆盖**：使用中、维修中、在库、闲置、运行中、报废
- 数据库文件一旦创建，之后即使清空数据再重启也不会回灌演示数据（保护真实数据不被覆盖）。
- 如需重新获得演示数据：停止框架 → 删除 `data/cmdb.db` → 重新启动即可。

### 1.4 插件配置文件（自动生成）

- `data/config.yaml` 由插件启动时自动生成，内容仅含版本号与生成时间。
- 版本号以 `plugin.py` 的 `get_metadata()` 为唯一来源，升级后重启自动同步。
- 文件缺失或损坏时会在下次启动自动重建，请勿手工编辑。

## 3. 资产录入

### 3.1 新建资产

1. 进入「IT 资产」或「办公/实物资产」页，点击「新建资产」。
2. 填写表单（按折叠区分为常用信息、采购合同、归属位置、系统信息、端口信息）。
3. **资产编号**：
   - **留空**：系统自动生成，格式 `前缀-YYYYMMDD-NN`（如 `IT-20260826-00`）。
   - **手填**：必须符合格式规则，且不与现有编号重复。
4. 点击「保存」，成功后自动刷新列表。

### 3.2 资产编号规则

```
格式：前缀-年月日-2位序号
示例：IT-20260826-00、OF-20260826-01、PE-20260826-00

前缀对照：
  IT设备 → IT
  办公家具 → OF
  生产设备 → PE
  其他分类 → AS

序号规则：
  - 当日同分类内递增，从 00 开始
  - 每日每分类最多 100 个（序号 00-99）
  - 日期必须为真实日历日期（如 2026-02-30 会拒绝）
```

### 3.3 资产字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 资产名称 | 是 | 资产的显示名称 |
| 资产编号 | 否 | 留空自动生成；手填须符合 `前缀-年月日-2位序号` |
| 资产分类 | 是 | IT设备 / 办公家具 / 生产设备（由页面限定） |
| 子类 | 否 | 如 服务器/交换机/笔记本/办公桌 等（可自定义输入） |
| 品牌/型号/SN | 否 | 设备标识信息 |
| 颜色/存储/内存 | 否 | 设备属性（IT 设备常用） |
| 使用人/部门 | 否 | 归属信息 |
| 存放位置 | 否 | 非上架设备的物理位置描述 |
| 状态 | 是 | 使用中/在库/维修中/闲置/运行中/报废（默认：在库） |
| 合同号/供应商 | 否 | 采购合同信息 |
| 购买日期/原值 | 否 | 采购信息，原值用于报表统计 |
| 保修到期 | 否 | 维保管理依据，格式 YYYY-MM-DD |
| 盘点时间 | 否 | 资产盘点记录，格式 YYYY-MM-DD |
| 备注 | 否 | 自由文本备注 |
| 所在机柜/U位/U高 | 条件 | IT 设备上架时填写（仅 IT 资产页显示） |
| 系统信息 | 条件 | IT 设备可添加多条 IP/登录方式/端口/账号信息 |
| 端口信息 | 条件 | 网络设备可添加端口（端口号/名称/速率/MAC/IP/对端） |

### 3.4 编辑资产

- 点击行内「编辑」按钮，弹出与新建相同的表单，预填当前值。
- 编辑时可修改资产编号（需重新校验格式与唯一性）。
- 编辑时保留原分类（即使不在本页面范围内也能编辑）。

### 3.5 删除资产

- 单条删除：点击行内「删除」按钮，二次确认后删除。
- 批量删除：勾选多条 → 点击「批量删除」→ 二次确认。
- 删除不可逆，关联端口一并删除（ON DELETE CASCADE）。

## 4. 翻页、排序与筛选

### 4.1 列表分页

- 默认每页 10 条，可切换 5 / 10 / 20 / 50 条/页。
- IT/实物资产页采用前端分页（全量拉取后客户端切片）。

### 4.2 排序

- 点击列头排序图标，支持升序/降序/取消排序。
- 支持排序的列：资产编号、名称、子类、品牌、颜色、使用人、状态、维保到期、盘点时间。

### 4.3 筛选

- 点击列头筛选图标，弹出多选下拉，勾选值后自动筛选。
- 支持筛选的列与排序列相同。

### 4.4 搜索

- 搜索框支持关键字模糊匹配（名称/编号/使用人/部门/颜色等）。
- 按回车或点击「查询」触发搜索，清空搜索框自动恢复全量。

## 5. 多选批量操作

### 5.1 批量更新盘点时间

1. 勾选目标资产（复选框在每行左侧）。
2. 点击「批量更新盘点时间」按钮。
3. 选择盘点日期 → 确认。
4. 后端批量更新 `inventory_time` 字段。

### 5.2 批量删除

1. 勾选目标资产。
2. 点击「批量删除」按钮。
3. 二次确认（提示不可恢复）。
4. 后端批量删除（关联端口一并删除）。

## 6. CSV 批量导入

### 6.1 操作流程

1. 点击「下载导入模板」获取 `cmdb_import_template.csv`。
2. 按模板内注释说明填写数据（`#` 开头行为注释，导入时自动跳过）。
3. 点击「CSV 导入」选择填写好的 CSV 文件。
4. 查看导入结果（成功/失败条数 + 错误明细）。

### 6.2 CSV 模板列说明

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| asset_no | 否 | 留空自动生成 |
| name | **是** | 资产名称 |
| category | 否 | 分类，默认 IT设备 |
| subtype | 否 | 子类 |
| user | 否 | 使用人 |
| dept | 否 | 部门 |
| location | 否 | 位置 |
| status | 否 | 状态，默认在库 |
| brand / model / sn | 否 | 设备标识 |
| contract_no / supplier | 否 | 合同信息 |
| purchase_date | 否 | 采购日期 YYYY-MM-DD |
| price | 否 | 原值（数字，单位元） |
| warranty_expire | 否 | 保修到期 YYYY-MM-DD |
| note | 否 | 备注 |
| rack_id | 条件 | 上架设备填写已存在的机柜编号 |
| u_start / u_height | 条件 | 上架设备填写 U 位 |

### 6.3 导入规则

- 仅支持 CSV 格式（不支持 xlsx）。
- 文件含 BOM 时自动去除。
- 字段内含逗号时用英文双引号包裹。
- name 为空的行自动跳过。
- 编号重复的行进入失败列表。
- U 位冲突或超出机柜总 U 数的行进入失败列表。
- 子类为「交换机/路由器/防火墙/AP/无线AP」时自动标记为网络设备。

## 7. 机柜 U 位管理

### 7.1 机柜视图（IT 资产页）

- 切换到「机柜视图」标签页，以卡片形式展示所有机柜。
- 每个卡片显示：机柜编号、名称、位置、总 U 数、已用/可用 U 数、使用率、U 位占用缩略图。

### 7.2 新建机柜

1. 在机柜视图页点击「新建机柜」。
2. 填写机柜编号（必填、唯一、创建后不可改）、名称、位置、总 U 数（默认 42U）、状态。
3. 保存后自动刷新列表。

### 7.3 设备上架

1. 编辑 IT 资产，展开「归属与位置」折叠区。
2. 选择「所属机柜」、填写「起始 U 位」和「U 高」。
3. 保存时后端校验：
   - 机柜必须存在。
   - 起始 U 位 ≥ 1，U 高 ≥ 1。
   - 起始 U 位 + U 高 - 1 ≤ 机柜总 U 数。
   - 不得与同机柜其他资产的 U 位区间重叠。

### 7.4 设备下架（移出机柜）

- 在机柜 U 位详情弹窗中，点击已占用 U 位旁的「移出」按钮。
- 仅清空资产的 `rack_id` / `u_start` / `u_height`，**资产台账保留**。

### 7.5 编辑/删除机柜

- **编辑**：修改机柜名称/位置/总 U 数/状态。调小总 U 数时若导致已上架设备越界会被拒绝。
- **删除**：
  - 机柜内无设备：直接删除。
  - 机柜内有设备：默认拒绝，提示先移出设备。确认后可「解绑并删除」（先解绑下架，再删机柜，资产台账不丢）。

## 8. 维保管理

### 8.1 过保预警

- 「维保管理」页按保修到期时间列出资产，分为两个区域：
  - **已过保/即将到期（≤30天）**：红色/橙色警告条，显示剩余天数或已过保天数。
  - **正常维保中**：表格列出剩余天数 > 30 天的资产。

### 8.2 续保操作

- 点击「续保」按钮，选择新的保修到期日期。
- 后端更新资产的 `warranty_expire` 字段。

### 8.3 报废操作

- 点击「报废」按钮，确认后将资产状态改为「报废」。
- 报废后该资产不再参与维保统计。

## 9. 报表中心

### 9.1 三种报表

| 报表 | 内容 | 用途 |
| --- | --- | --- |
| 资产盘点报表 | 全量资产明细（编号/名称/分类/子类/使用人/部门/位置/状态/原值/保修到期） | 资产盘点核对 |
| 部门资产汇总表 | 按部门统计资产数与原值合计 | 部门资产分析 |
| 维保到期预警报表 | 即将/正常到期资产清单（含剩余天数） | 续保决策 |

### 9.2 导出格式

- **HTML**：带样式的网页报表，可直接浏览器打印。
- **CSV**：带 UTF-8 BOM，Excel 打开中文不乱码。
- CSV 导出时自动消毒以 `= + - @ \t \r` 开头的字段（防止公式注入）。

## 10. 数据备份与恢复

### 10.1 全量备份导出

- 点击「报表中心」→「全量备份导出」。
- 导出 JSON 文件，包含：全部资产（含端口）+ 全部机柜。
- 文件名格式：`cmdb_backup_YYYYMMDD_HHMMSS.json`。

### 10.2 备份导入恢复

1. 选择导入模式：
   - **合并更新（merge）**：按资产编号/SN 匹配，存在则更新、不存在则新增（安全，不丢数据）。
   - **覆盖还原（overwrite）**：清空现有数据后整表还原（危险，用于灾难恢复）。
2. 选择 JSON 备份文件。
3. 点击「开始导入」，查看结果（新增/更新/跳过/错误计数）。

### 10.3 备份文件格式

```json
{
  "meta": {
    "type": "cmdb-backup",
    "version": "20260804-V4",
    "exported_at": "2026-08-26T10:00:00",
    "asset_count": 13,
    "rack_count": 5
  },
  "racks": [ ... ],
  "assets": [
    {
      "asset_no": "IT-20230601-01",
      "name": "Dell PowerEdge R750",
      "category": "IT设备",
      "ports": [ ... ],
      "config": { "system_info": [ ... ] }
    }
  ]
}
```

## 11. 端口配置

### 11.1 端口编辑（资产编辑表单）

- 仅 IT 资产显示「端口信息」折叠区。
- 支持手动添加端口、自动生成批量端口。
- 端口字段：端口号、名称、速率、MAC 地址、IP 地址、对端设备、对端端口、备注、状态。

### 11.2 端口状态

| 状态 | 含义 |
| --- | --- |
| connected | 已连接 |
| disconnected | 未连接 |
| disabled | 禁用 |

### 11.3 网络设备自动识别

- 子类为「交换机/路由器/防火墙/AP/无线AP」的资产在 CSV 导入时自动标记为网络设备。
- 标记后即使暂无端口，端口区也会显示（便于后续录入）。

## 12. 仪表盘

### 12.1 四个统计卡片

| 卡片 | 数据来源 |
| --- | --- |
| 资产总数 | `COUNT(*) FROM assets WHERE category <> '机柜'` |
| IT 资产 | `COUNT(*) FROM assets WHERE category = 'IT设备'` |
| 机柜总数 | `COUNT(*) FROM racks` + 已占/总 U 数 |
| 即将过保 | `warranty_expire ≤ 30天` 的资产数量 |

### 12.2 最近登记资产

- 展示最近 8 条资产，支持排序/筛选。
- 点击行可打开资产详情。
